BACKGROUND OF THE INVENTION

FIELD OF THE INVENTION

[0003] The present invention relates generally to the field of neuromodulation, and more particularly to a system and method for adaptive closed-loop network-level targeting of brain stimulation using real-time electroencephalography (EEG) feedback and multi-node temporal interference (TI) stimulation.

DESCRIPTION OF THE PRIOR ART

[0004] Existing neuromodulation techniques, such as transcranial magnetic stimulation (TMS) and transcranial direct current stimulation (tDCS), often employ static, single-target approaches. These methods deliver stimulation to a predefined brain region without dynamically adapting to the individual's brain state or the functional network involved in a specific task. This can lead to suboptimal stimulation parameters and limited efficacy. Furthermore, prior art methods struggle to target deep brain structures non-invasively and with high spatial resolution. Temporal interference (TI) stimulation, as described in prior art such as Beanato et al., has shown promise in non-invasively targeting deep brain structures. However, existing TI approaches often lack the ability to adapt to the dynamic changes in brain activity and network connectivity during cognitive or motor tasks.

[0005] Furthermore, current neuromodulation techniques often fail to account for individual variability in brain anatomy and functional organization, leading to inconsistent treatment outcomes. A need exists for a neuromodulation system that can adapt to individual brain states in real-time, target multiple nodes within a functional network, and dynamically adjust stimulation parameters to optimize therapeutic efficacy.

BRIEF SUMMARY OF THE INVENTION

[0006] The present invention overcomes the limitations of the prior art by providing an adaptive closed-loop network targeting system that integrates real-time EEG feedback with multi-node TI stimulation. The system identifies the user's endogenous neural oscillations associated with a target skill (e.g., motor execution) and employs dynamic spatial steering to apply precisely timed TI stimulation to multiple, coordinated nodes within the relevant functional brain network (e.g., motor cortex and cerebellum). This closed-loop system continuously adjusts stimulation parameters to reinforce the optimal brain state for peak performance, moving beyond the static, single-target approach.

[0007] In one embodiment, the system comprises a non-invasive neurophysiological sensing interface (e.g., EEG) configured to capture real-time EEG data, a multi-node TI stimulation apparatus comprising at least three pairs of electrodes, and a processor in communication with the interface and the apparatus. The processor is configured to identify a functional network by performing real-time source localization on the EEG data, extract phase-coherence metrics and spatial centroids for each neural node, calculate an adaptive coordinate transformation to map the non-stationary spatial centroids to current-steering vectors, dynamically steer the TI stimulation to track the non-stationary centroids, generate a volumetric destructive interference null-zone, and modulate the beat frequency of the TI stimulation to maintain a phase-locked state with the extracted phase-coherence metric.

DETAILED DESCRIPTION OF THE INVENTION

[0011] The present invention provides an adaptive closed-loop network targeting system that leverages real-time EEG feedback and multi-node TI stimulation to enhance neuromodulation efficacy. The system comprises three main components: a non-invasive neurophysiological sensing interface, a multi-node TI stimulation apparatus, and a processor.

[0012] The non-invasive neurophysiological sensing interface is preferably an EEG system capable of capturing high-density EEG data with sufficient temporal resolution to track real-time brain activity. The EEG system comprises a plurality of electrodes strategically positioned on the scalp to capture electrical activity from various brain regions. The EEG data is then pre-processed to remove artifacts and noise, and subjected to source localization algorithms to identify the spatial location of neural sources contributing to the observed EEG signals.

[0013] The multi-node TI stimulation apparatus comprises at least three pairs of electrodes positioned on the scalp to deliver TI stimulation to multiple target brain regions. Each electrode pair is driven by a separate waveform generator, allowing for independent control of the amplitude, frequency, and phase of the stimulation current. The TI stimulation parameters are dynamically adjusted based on the real-time EEG feedback to optimize the stimulation efficacy.

[0014] The processor is a computing device configured to perform real-time source localization on the EEG data, extract phase-coherence metrics and spatial centroids for each neural node, calculate an adaptive coordinate transformation to map the non-stationary spatial centroids to current-steering vectors, dynamically steer the TI stimulation to track the non-stationary centroids, generate a volumetric destructive interference null-zone, and modulate the beat frequency of the TI stimulation to maintain a phase-locked state with the extracted phase-coherence metric. The processor implements a closed-loop feedback controller that continuously adjusts the stimulation parameters based on the ongoing EEG activity.

[0015] The adaptive coordinate transformation includes a depth-compensation algorithm that modifies the relative current amplitudes of the electrode pairs to maintain focal maxima at varying cortical depths as the neural nodes migrate spatially during task execution. This ensures that the TI stimulation remains focused on the target brain regions despite their dynamic movement.

[0016] Furthermore, the processor may implement a closed-loop feedback controller that adjusts the intensity of the TI stimulation at each neural node independently based on the local power spectral density of the EEG data at each node's respective spatial centroid. This allows for individualized optimization of the stimulation parameters based on the specific neural activity patterns observed in each subject.

[0017] In one embodiment, the processor is configured to detect a motor-skill-related theta-gamma coupling biomarker and, in response, set the beat frequency to match the endogenous theta frequency while pulsing the amplitude of the TI stimulation at a gamma frequency to facilitate cross-frequency coupling. This approach can enhance motor learning and rehabilitation by promoting the integration of neural activity across different frequency bands.

CLAIMS

  1. A system for adaptive closed-loop network-level neuromodulation, comprising: a non-invasive neurophysiological sensing interface configured to capture real-time electroencephalography (EEG) data; a multi-node temporal interference (TI) stimulation apparatus comprising at least three pairs of electrodes; and a processor in communication with the interface and the apparatus, the processor configured to: (a) identify a functional network comprising a first neural node and a second neural node by performing real-time source localization on the EEG data; (b) extract a phase-coherence metric and a spatial centroid for each of the first and second neural nodes; (c) calculate an adaptive coordinate transformation that maps the non-stationary spatial centroids of the first and second neural nodes to a set of current-steering vectors for the TI stimulation apparatus; (d) dynamically steer the TI stimulation by adjusting current ratios and phase offsets across the at least three pairs of electrodes to track the non-stationary spatial centroids, while simultaneously generating a volumetric destructive interference null-zone spatially localized within the volume between the first and second neural nodes to isolate the neural nodes from intervening neural tissue; and (e) modulate a beat frequency of the TI stimulation to maintain a phase-locked state with the extracted phase-coherence metric, thereby reinforcing synchronous oscillations within the functional network.
  2. The system of claim 1, wherein the processor is configured to generate the volumetric destructive interference null-zone by driving a subset of the electrodes with an auxiliary waveform phase-inverted relative to the interference envelope at the midpoint between the first and second neural nodes.
  3. The system of claim 1, wherein the adaptive coordinate transformation includes a depth-compensation algorithm that modifies the relative current amplitudes of the at least three pairs of electrodes to maintain focal maxima at varying cortical depths as the first and second neural nodes migrate spatially during task execution.
  4. The system of claim 1, wherein the processor implements a closed-loop feedback controller that adjusts the intensity of the TI stimulation at the first and second neural nodes independently based on the local power spectral density of the EEG data at each node's respective spatial centroid.
  5. The system of claim 1, wherein the processor is configured to detect a motor-skill-related theta-gamma coupling biomarker and, in response, set the beat frequency to match the endogenous theta frequency while pulsing the amplitude of the TI stimulation at a gamma frequency to facilitate cross-frequency coupling.
  6. The system of claim 1, wherein the non-invasive neurophysiological sensing interface is a high-density EEG system comprising at least 64 electrodes.
  7. The system of claim 1, wherein the processor performs real-time source localization using a beamforming algorithm.
  8. The system of claim 1, wherein the phase-coherence metric is calculated using a phase-locking value (PLV) algorithm.
  9. The system of claim 1, wherein the adaptive coordinate transformation is implemented using a Kalman filter.
  10. A method for adaptive closed-loop network-level neuromodulation using the system of claim 1, comprising the steps of: (a) acquiring real-time EEG data from a subject; (b) identifying a functional network within the subject's brain; (c) applying multi-node temporal interference (TI) stimulation to the identified functional network; and (d) dynamically adjusting the TI stimulation parameters based on the real-time EEG data to reinforce synchronous oscillations within the functional network.

ABSTRACT OF THE DISCLOSURE

[0018] A system for adaptive closed-loop network-level neuromodulation is disclosed. The system uses real-time EEG to identify the user's endogenous neural oscillations associated with a target skill (e.g., motor execution). It then employs dynamic spatial steering to apply precisely timed TI stimulation to multiple, coordinated nodes within the relevant functional brain network (e.g., motor cortex and cerebellum). This closed-loop system continuously adjusts stimulation parameters to reinforce the optimal brain state for peak performance, moving beyond the static, single-target approach.
