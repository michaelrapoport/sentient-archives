Claims

A distributed neural decoding system for phase-preserved BCI operation during hardware saturation, the system comprising: a local BCI terminal comprising a neural sensor array and a local processor configured to execute a primary control loop via a low-rank projection of a detected neural manifold; a latent space decomposer configured to, upon detecting a hardware saturation event, bifurcate a high-dimensional neural signal into (i) a primary low-rank component for local processing and (ii) a high-rank residual component for remote offloading; a secondary edge device communicatively coupled to the local BCI terminal and configured to calculate a high-fidelity correction vector from the high-rank residual component; and a phase-synchronous reintegration unit comprising a Direct Memory Access (DMA) controller and a shadow register bank, the unit configured to: (a) receive the high-fidelity correction vector from the secondary edge device; (b) align the high-fidelity correction vector with the current temporal phase of the primary control loop to prevent decoding phase-slip; and (c) perform an atomic swap of active weights in the local processor with updated weights derived from the high-fidelity correction vector during a non-critical clock cycle, thereby maintaining high-fidelity decoding accuracy while the local processor is operating in a reduced-rank state to mitigate hardware saturation.

Description

A system for offloading neural data to secondary edge devices when local hardware saturation is detected.
