Context-Switched Predictive Models on a Neuromorphic Co-Processor

Inventor: Michael Rapoport from Polaritronics Inc.

Abstract

A system for The SNN co-processor is architected to store multiple, smaller, specialized predictive models instead of one large, general-purpose model. A lightweight meta-network analyzes the incoming data stream's context (e.g., 'speech' vs 'music', 'highway' vs 'city street') and rapidly switches the active predictive model to the one best trained for that context. (Based on: Improvement on US Patent 11,328,197)

Claims

1. A neuromorphic processing system comprising: a memory storing a plurality of specialized predictive models; a spiking neural network (SNN) co-processor configured to execute an active model selected from the plurality of specialized predictive models; and a context-aware controller comprising a meta-network, the controller configured to: monitor an incoming data stream; determine a current context from the incoming data stream using the meta-network; and trigger a context-switch of the active model on the SNN co-processor to a specific specialized predictive model corresponding to the current context. 2. The neuromorphic processing system of claim 1, wherein the meta-network is a lightweight neural network having a lower computational complexity than each of the plurality of specialized predictive models. 3. The neuromorphic processing system of claim 1, wherein the plurality of specialized predictive models are spiking neural networks configured to process temporal data patterns unique to specific environmental domains. 4. The neuromorphic processing system of claim 1, wherein the context-switch comprises reloading synaptic weights of the SNN co-processor from the memory within a fixed number of clock cycles to maintain real-time processing of the incoming data stream. 5. The neuromorphic processing system of claim 1, wherein the incoming data stream comprises multimodal sensor data, and the meta-network is configured to identify a change in environment based on a shift in signal statistics within the multimodal sensor data.
