Multi-Modal Temporal Variational Autoencoder

Abstract

A system for A specific neural network architecture that learns a unified latent representation from disparate, time-series sensor streams like video and proprioceptive data.

Claims

1. A system for multi-modal temporal representation learning in an embodied agent, the system comprising: a plurality of modality-specific encoders configured to process heterogeneous time-series sensor streams having disparate sampling rates; a cross-modal temporal attention module configured to compute an alignment matrix that temporally synchronizes asynchronous features from the heterogeneous time-series sensor streams into a unified feature stream; a hierarchical variational bottleneck comprising a macro-temporal level representing global trajectory dynamics and a micro-temporal level representing local perturbations, wherein the macro-temporal level is configured to receive the unified feature stream; a physics-informed transition module configured to constrain probabilistic state transitions within the macro-temporal level based on a predefined physical dynamics model of the embodied agent; and a plurality of modality-specific decoders; wherein the macro-temporal level and the micro-temporal level are coupled such that a latent state at the macro-temporal level dynamically defines the means and covariances of a Gaussian Mixture Model (GMM) prior for the transition distribution of the micro-temporal level, the GMM prior functioning to map high-frequency sensor noise from the unified feature stream onto a manifold constrained by the global trajectory dynamics. 2. The system of claim 1, wherein the cross-modal temporal attention module comprises a multi-head scaled dot-product attention mechanism where queries are derived from a first sensor stream having a first sampling rate and keys and values are derived from a second sensor stream having a second sampling rate higher than the first sampling rate, the alignment matrix representing a weighted temporal mapping between the first and second sampling rates. 3. The system of claim 1, wherein the physics-informed transition module is configured to calculate a divergence between a latent state transition and a trajectory predicted by a set of non-holonomic ordinary differential equations (ODEs), and further configured to minimize said divergence via a Lagrangian multiplier during training to enforce physical consistency at the macro-temporal level. 4. The system of claim 1, further comprising a temporal re-projection unit configured to perform an iterative refinement of the macro-temporal latent state by back-propagating the reconstruction error of the micro-temporal level through the GMM prior, thereby correcting for cumulative drift in the global trajectory dynamics. 5. The system of claim 1, wherein the modality-specific encoders include a convolutional neural network for video data and a recursive neural network for proprioceptive data, and wherein the cross-modal temporal attention module is positioned as an intermediary layer between said encoders and the hierarchical variational bottleneck.

Description

A specific neural network architecture that learns a unified latent representation from disparate, time-series sensor streams like video and proprioceptive data.
