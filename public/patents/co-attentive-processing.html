Adaptive Co-Attentive Processing Systems and Methods via Large Language Model (LLM) and Spiking Neural Network (SNN) Feedback Loops

ABSTRACT

A system and method for hybrid neural processing implement an adaptive feedback loop between a Large Language Model (LLM) and a Spiking Neural Network (SNN) co-processor. The LLM generates initial attention scores for a token sequence, while the SNN co-processor receives encoded data from the LLM to generate temporal feedback signals based on spike-based filtering. These signals are utilized to refine the LLM's attention weights in real-time, enabling sparse, saliency-driven processing. The system leverages the temporal resolution of neuromorphic hardware to modulate the transformer-based attention mechanism, enhancing computational efficiency and context sensitivity.

FIELD OF THE INVENTION

The present invention relates generally to the field of artificial intelligence and machine learning. More specifically, the invention relates to hybrid architectures combining transformer-based models with neuromorphic computing systems to optimize attention mechanisms through temporal feedback.

BACKGROUND OF THE INVENTION

Large Language Models (LLMs) typically utilize the self-attention mechanism to weight the importance of different tokens in a sequence. While effective, standard attention mechanisms are computationally intensive, often scaling quadratically with sequence length. Furthermore, these mechanisms often fail to account for fine-grained temporal saliency that might be present in dynamic data streams.

Spiking Neural Networks (SNNs), operating on neuromorphic principles, excel at temporal pattern recognition and energy-efficient processing through sparse activations (spikes). However, SNNs currently lack the complex semantic reasoning capabilities of deep transformer models. There exists a need in the art for a system that combines the high-level reasoning of LLMs with the low-latency, temporal filtering capabilities of SNNs to create more adaptive and efficient processing pipelines.

SUMMARY OF THE INVENTION

In view of the foregoing, the present invention provides a method and system for adaptive co-attentive processing. The system comprises an LLM configured to generate initial attention scores and an SNN co-processor configured to monitor the internal states of the LLM.

Specifically, the LLM hidden states or input embeddings are encoded into spike trains. The SNN processes these spikes to identify salient temporal features. The output of the SNN, in the form of an integrated firing rate or temporal signal, is fed back into the LLM's attention heads as a gain factor. This multiplicative adjustment refines the attention weights, effectively "pruning" or "boosting" specific tokens based on the SNN's real-time analysis. This result is a co-attentive system where the SNN acts as a high-speed, sparse filter for the LLM's intensive computational layers.

DETAILED DESCRIPTION OF THE PREFERRED EMBODIMENTS

Referring to FIG. 1, the system for adaptive co-attentive processing 100 comprises an LLM 102 and an SNN co-processor 104. The LLM 102 is preferably a transformer-based architecture utilizing a multi-head self-attention mechanism. The SNN co-processor 104 is implemented on neuromorphic hardware, such as a specialized integrated circuit designed for spike-based computation.

As tokens are processed by the LLM 102, a hidden state vector \( \mathbf{h} \) is generated for each token position. This vector is passed to a spike encoder within the SNN co-processor 104. In a preferred embodiment, the encoder utilizes a rate-coding scheme where the magnitude of the vector components determines the firing frequency of input neurons in the SNN. Alternatively, a latency-coding scheme may be used, where the magnitude determines the timing of the first spike within a temporal window \( T \).

The SNN 104 comprises a plurality of Leaky Integrate-and-Fire (LIF) neurons. The dynamics of each neuron \( j \) are governed by the differential equation:

\[ \tau_m \frac{dV_j}{dt} = -(V_j(dt) - V_{rest}) + R \cdot I(t) \]

where \( V_j \) is the membrane potential, \( \tau_m \) is the membrane time constant, and \( I(t) \) represents the input current derived from the LLM hidden states. When \( V_j \) exceeds a threshold \( V_{th} \), a spike is generated and \( V_j \) is reset.

The temporal feedback signal 106 is derived from the firing rate \( \rho \) of the SNN neurons over a sliding window. This signal is used to compute a gain factor \( G \). For a given attention score \( A_{ij} \) between token \( i \) and token \( j \), the refined attention score \( A'_{ij} \) is calculated as:

\[ A'_{ij} = \text{softmax} \left( \frac{Q_i K_j^T}{\sqrt{d_k}} \right) \cdot G(\rho_j) \]

wherein \( G(\rho_j) \) is a function of the firing rate associated with token \( j \). If the SNN 104 identifies token \( j \) as highly salient (high firing rate), \( G \) increases the attention weight. If the SNN 104 filters token \( j \) as noise or low-priority background information, \( G \) decreases, thereby sparsifying the LLM's attention map.

This feedback loop 106 allows the LLM 102 to dynamically adjust its focus based on real-time temporal filters that are more computationally efficient than full transformer layer re-computation. This is particularly advantageous in streaming data applications, such as real-time audio processing or high-frequency financial data analysis, where the SNN 104 can detect temporal anomalies faster than the LLM 102.

CLAIMS

1. A method for adaptive co-attentive processing in a hybrid neural system, the method comprising:
    generating, by a large language model (LLM), a set of initial attention scores corresponding to a sequence of input tokens;
    processing, by a spiking neural network (SNN) co-processor, data associated with the sequence of input tokens to generate a temporal feedback signal; and
    refining the set of initial attention scores within the LLM based on the temporal feedback signal to produce adaptive attention weights for generating an output sequence.
2. The method of claim 1, wherein processing data by the SNN co-processor comprises encoding hidden state vectors of the LLM into a plurality of spikes according to a rate-coding or a latency-coding scheme.
3. The method of claim 1, wherein refining the set of initial attention scores comprises applying a multiplicative gain factor to the initial attention scores, the gain factor being derived from an integrated firing rate of the SNN co-processor over a specific temporal window.
4. The method of claim 1, wherein the SNN co-processor is configured to operate as a real-time temporal filter to identify salient features within the sequence of input tokens that trigger sparse activation feedback to the LLM.
5. The method of claim 1, wherein the LLM and the SNN co-processor are executed on a heterogeneous hardware platform comprising at least one neuromorphic processor dedicated to the SNN co-processor and at least one general-purpose accelerator dedicated to the LLM.
6. A system for adaptive neural processing, comprising:
    a transformer-based memory storing instructions for a large language model (LLM);
    a neuromorphic processor implementing a spiking neural network (SNN);
    wherein the LLM is configured to provide internal state data to the SNN; and
    wherein the SNN is configured to provide a gain control signal to an attention module of the LLM to modulate attention weights based on spike density.
