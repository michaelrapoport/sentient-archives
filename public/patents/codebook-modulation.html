Adaptive Codebook Modulation via Variant Subspace Context

Inventor: Michael Rapoport from Polaritronics Inc.

Abstract

A system for This concept enhances the original idea by utilizing the session-variant subspace instead of discarding it. The variant subspace, which captures user state like fatigue or signal drift, is used to generate a real-time 'context vector'. This vector dynamically modulates the 'invariant' codebook entries via a mechanism like Feature-wise Linear Modulation (FiLM) before the final decoding step. This allows the core motor primitives to remain stable while the system adapts to the specific conditions of the current session on-the-fly. Claims

1. A system for adaptive signal decoding, the system comprising: a signal processor configured to: a. receive a set of input signals from a user; b. decompose the set of input signals into a session-invariant subspace and a session-variant subspace via a projection matrix constrained by an orthogonality loss; c. generate a dynamic context vector by processing the session-variant subspace through a sequence-to-vector encoder, wherein the dynamic context vector characterizes non-stationary signal drift and user physiological state; d. modulate a plurality of invariant motor primitives in a codebook via a modulation mechanism comprising a hypernetwork, wherein the hypernetwork maps the dynamic context vector to a set of affine transformation parameters for a Feature-wise Linear Modulation (FiLM) layer, the FiLM layer applying the affine transformation to the invariant motor primitives to generate a set of session-adapted motor primitives; and e. decode the set of input signals by computing a similarity measure between the session-invariant subspace projection of the input signals and the set of session-adapted motor primitives to output a control command. 2. The system of claim 1, wherein the sequence-to-vector encoder comprises a Gated Recurrent Unit (GRU) configured to extract temporal dependencies from the session-variant subspace at a frequency matched to the sampling rate of the input signals. 3. The system of claim 1, wherein the invariant motor primitives are pre-trained on a multi-subject dataset and remain fixed within the codebook, while the hypernetwork dynamically updates the session-adapted motor primitives in real-time. 4. The system of claim 1, wherein the affine transformation parameters comprise a scaling vector and a shifting vector that adjust the manifold orientation of the invariant motor primitives within a latent feature space. 5. The system of claim 1, wherein the signal processor is further configured to update the projection matrix based on a reconstruction error of the session-variant subspace to maintain the orthogonality constraint during a continuous user session.
