# SENTIENT_ARCHIVES

AGI Prototype Repository // v2.4.0

A curated collection of advanced neural architectures, fungal computing substrates, and closed-loop neuromorphic control systems. Each model represents a step towards verifiable Artificial General Intelligence.

## Project Features

- **Neural Background**: Real-time D3.js force-directed graph simulation.
- **Archive Grid**: Explore 34 advanced AGI prototype models.
- **Technical Specifications**: Full patent-level documentation for every project integrated directly into the archive.
- **Responsive Interface**: Optimized for high-resolution desktop and mobile terminals.

## Tech Stack

- **React 19**
- **Vite 6**
- **TypeScript 5**
- **D3.js** (Neural Topology)
- **Lucide-React** (Iconography)
- **Tailwind CSS** (Styling)

## Live Archive

View the archive live at: https://michaelrapoport.github.io/sentient-archives/

## Local Development

1. Install dependencies:
   `npm install`
2. Run the dev server:
   `npm run dev`
3. Build for production:
   `npm run build`
